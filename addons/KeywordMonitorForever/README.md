# WOW Keyword Monitor — 无限服独立版 (0.1.1-alpha)

基于 Classic Era / Hardcore 的 0.3.10-alpha 功能创建的独立无限服版本。

- 适用：魔兽世界「无限」/ WoW Forever，Interface 16001，1.60.1
- 安装路径：`World of Warcraft/_forever_/Interface/AddOns/WOW_keywordmonitor_forever/`；以实际客户端目录为准
- 打开窗口：`/wkmf` 或 `/kwmf`，与经典旧世版的 `/wkm` 分离
- 配置数据：`WOWKeywordMonitorForeverDB`，不读取也不修改经典旧世版配置
- 功能：公共/公会聊天、布尔匹配规则、每规则 ON/OFF 滑动开关、历史和提醒、角色好友备注、原生黑名单
- 临时监控：`/wkmf 黑莲花`（公共），`/wkmf tg 黑莲花`（公会），`/wkmf tl` 查看
- 屏幕大字：使用独立 UIParent 悬浮提示层（约 4.5 秒自动隐藏），不再依赖 `RaidNotice_AddMessage` 的团队警告框
- 显示层测试：`/wkmf alerttest`，不要求有真实聊天、匹配规则或开启全局监听；即便设置中关闭“屏幕大字”，也能强制显示测试样例
- 诊断：`/wkmf diag` 查看全局监听、屏幕大字开关、公共/公会事件数量、可读消息、命中、黑名单静默、通知次数、大字显示次数
- 其他诊断：`/wkmf scopes` 查看已保存规则频道，`/wkmf secrets` 查看受保护消息跳过计数

## 无限服客户端限制

现代版客户端的聊天事件（尤其在通信限制激活时）可能返回受保护 Secret Value，插件无法合法读取其内容或用作关键词搜索。本版读取前先使用 `issecretvalue` 检查，跳过受保护消息，避免报错；这意味着可能出现受限聊天漏检。不会规避游戏安全限制。

**0.1.1-alpha 仍为需要游戏实测的适配测试包**：已分离命名空间、SavedVariables、插件目录、快捷命令和关键聊天事件保护。某些 UI、好友 API、兼容性仍需无限服客户端实测。

经典旧世/硬核服源代码：`addons/KeywordMonitor/`；无限服源代码：`addons/KeywordMonitorForever/`。两个版本分别打包，不混装。

## 大字未显示时的检查方法

1. 游戏里输入 `/wkmf alerttest`。如果屏幕上方中央出现“关键词提醒 · 测试”，独立显示层正常。
2. 打开 `/wkmf`，确认“全局监听 ON”、“屏幕大字”已勾选；选择规则时，确保规则自身为 ON，且对应“公共”/“公会”频道滑动开关为 ON。
3. 输入 `/wkmf diag` 查看统计值。本次登录期间收到消息，公共/公会事件数应增加；若“受保护跳过”增加但“可读取”不增加，说明消息受无限服客户端 API 限制。
4. 输入 `/wkmf test 示例消息文本` 检查公共频道规则，或 `/wkmf testguild 示例消息文本` 检查公会规则。这两个命令只测试匹配，不会显示大字。
5. 如果“去重后命中”增加，但“通知调用”始终为 0，检查发送者是否在原生黑名单或是否存在 Lua 错误。若“通知调用”增加但“大字显示”不增加，请确认屏幕大字开关是否开启。

`/wkmf alerttest` 是直接测试 UI，不会往历史记录添加假消息，也不触发真实聊天事件。统计只保存在本次登录内存中，`/reload` 后清零。
