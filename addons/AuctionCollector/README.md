# AuctionCollector · 0.4.1-alpha

面向国服 Classic Era/硬核服的拍卖行信息采集插件。插件只保存原始挂单页，不计算价格、库存或供需；不自动切换清单物品，不交易，也不在后台启动采集。

安装路径为 `Interface/AddOns/AuctionCollector/`，可与原关键词插件 `Interface/AddOns/WOW_keywordmonitor/` 共存。两者各自使用 SavedVariables：`AuctionCollectorDB` 与 `WOWKeywordMonitorDB`。

## 可编辑物品清单

初始清单保留：黑莲花、泰坦合剂、精炼智慧合剂、超级能量合剂、多重抗性合剂、化石合剂、石鳞鱼油。已移除格罗姆之血、梦叶草、冰盖草和山鼠草。

在面板中填写**国服拍卖行显示的物品名称**和**物品 ID**，点击「加入清单」即可添加；每项右侧的 **×** 可移除该项目。清单采用两列显示，面板会尽量利用屏幕高度；当前清单超出可见区域时可用鼠标滚轮查看。更改会保存在 `AuctionCollectorDB.watchlist`，重载后仍保留。名称和 ID 必须准确对应；清单不允许重复名称或重复 ID。删除清单项只影响以后的采集，不会删除历史扫描页。

## 自动连续分页

1. 打开拍卖行并输入 `/ac`，或直接在拍卖行打开时使用自动弹出的面板。
2. 点击清单中的一个物品。插件会查询该物品第一页，再按拍卖行查询冷却自动继续下一页，直到客户端报告已到末页。
3. 面板和聊天框显示正在查询的页数、已采集页数和挂单数。清单里的其他物品不会被自动扫描。
4. 需要中止时点击「停止自动翻页」或输入 `/ac stop`。若当前页已发出查询，插件会等该页返回并保存后停止后续查询。关闭拍卖行也会停止自动翻页。
5. **Esc 只关闭面板，不会中断已启动的采集。**重新输入 `/ac` 可重新打开。
6. 每次最多连续采集 200 页；遇到查询超时、空页、物品名称/ID 不匹配、分页总数异常或超过保护上限时，会停止并显示未完成状态，已成功取得的页仍会保留。

自动分页遵守 `CanSendAuctionQuery` 冷却，不尝试绕过客户端限速。Legacy AH 更新事件不带查询请求 ID；因此自动采集期间请勿在 AH 中切换其他搜索，也不要让其他拍卖行插件同时发起查询。结果物品名称或 ID 与选中项目不符时，本插件会拒绝保存该页并停止。相同物品的外部搜索仍无法由旧 API 完全区分。

分页按顺序在一段时间内采集，不是同一时刻的原子快照；扫描期间挂单变化可能影响后续页边界。每页分别保存，最多保留最近 200 页。插件不会自动扫描清单里的下一件物品。

## 游戏内状态面板

输入 `/ac` 打开或关闭面板。面板会显示当前采集状态、服务器和阵营、Legacy API 可用情况、最近扫描页、卖家字段/剩余时限档覆盖数、最近三条记录及 SavedVariables 读回状态。

| 状态 | 含义 |
|---|---|
| 正在等待 / 自动翻页中 | 已启动 AH 查询，或正在等查询冷却；尚不等于该批采集已完成 |
| 等待卖家名称解析 | AH 已返回，插件最多再等 2 秒读取卖家名，不会因此重发当前查询 |
| 自动采集完成 | 该物品最后一页已返回；所有页数据仍在内存中，等待 WoW 写入 SavedVariables |
| 自动翻页停止 / 查询失败 | 当前批次未完整结束；之前已保存的页仍可写盘 |
| 已从 SavedVariables 存档读回 | WoW 重载或重新登录后读回之前的扫描数据 |

数据写盘：点击「写盘并重载游戏界面」，或正常退出游戏。重新登录后面板显示「已从 SavedVariables 存档读回」表示插件从游戏存档读回数据；这**不代表已经上传 Azure**。macOS 文件路径通常为 `World of Warcraft/_classic_era_/WTF/Account/<账号>/SavedVariables/AuctionCollector.lua`。Mac 同步端应使用仓库中的安全 Lua SavedVariables 解析器，不要执行该 Lua 文件。

## 采集字段和限制

每个页面保存物品名称和 ID、页码、AH 报告总条目数、数量、起拍价、当前竞价、一口价、卖家角色、剩余时限档及采集时间。剩余时限 `time_left_bucket` 是客户端提供的 1–4 档类别，不是精确倒计时或挂单时间。卖家是角色名，不能据此确认账号或真人。

结果与查询名称或物品 ID 不匹配、查询超时或结果为空时，不会把不明页面伪装成成功扫描。即便返回所有字段，单页和连续分页也只代表观察到的 AH 查询结果，不等于全服总库存或成交量；挂单消失无法区分成交、撤单、到期或分页变化。

旧版本已在真实国服客户端验证过黑莲花查询能返回物品 ID、数量和价格；一次复测中 31/31 条记录均解析出卖家名。0.4.0-alpha 新增的可编辑清单和连续自动分页**尚待真实国服客户端验证**，包含新增物品名称、物品 ID、查询冷却行为和分页末页判断。0.4.1-alpha 的两列清单显示和自适应面板高度也尚未在真实客户端实测。Lua 模拟测试不能替代游戏实测。

## 命令

- `/ac` 或 `/ac ui`：打开/关闭面板
- `/ac probe`：显示 Legacy API、`C_AuctionHouse`、服务器、阵营和客户端 build
- `/ac items`：在聊天框列出当前物品清单及 ID
- `/ac scan N`：启动清单第 N 项的自动分页采集
- `/ac lotus`：启动黑莲花的自动分页采集
- `/ac stop`：停止当前自动分页
- `/ac status`：在聊天框和面板显示采集状态
- `/ac next`、`/ac page N`：仅供需要时手动查询一页；正常采集不需要使用

自动采集最多运行到 200 页保护上限。无自动交易、后台自动启动、模拟点击、反 AFK、绕过 API 冷却或读取游戏内存。
